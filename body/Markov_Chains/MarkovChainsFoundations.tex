A discrete-time Markov chain is a stochastic process that is a sequence of random variables $X_0, X_1, X_2, \ldots$ that is indexed by time points $t = 0,1,2,\ldots$ that possesses the Markov Property. As CITEprob.pdf describes, each $X_t$ belongs to a set $S$ known as the state space, where $X_t$ is the state of the chain at time $t$. This describes a discrete-time Markov chain, since the process moves in countable time steps $t = 0,1,2,\ldots$. The Markov property states that the distribution of the next state $X_{t+1}$ depends only on the current state $X_t$. Mathematically, that is shown as ( Markov chain package CITE CITE):
\begin{flalign*}
& \textbf{Markov Property} && \\
& \Pr(X_{t+1} = x_{t+1} \mid X_1 = x_1, \ldots, X_t = x_t) = \Pr(X_{t+1} = x_{t+1} \mid X_t = x_t) &&
\end{flalign*}

The probability that a discrete Markov chain moves from state $s_i$ to state $s_j$ is the transition probability $p_{ij}$, which is the conditional probability of state $s_j$ given the current state $s_i$ (CITE package). Mathematically, that is shown as:
\begin{flalign*}
& \textbf{Transition Probability} && \\
& p_{ij} = \Pr(X_1 = s_j \mid X_0 = s_i) &&
\end{flalign*}

These transition probabilities can be displayed in a transition matrix $P$. A transition matrix is a square matrix whose rows and columns list all the states. The rows represent $X_t$, the state at time $t$, while the columns represent $X_{t+1}$, the state at time $t+1$. Each cell represents the transition probability. 

One property a discrete-time Markov Chain can have is time-homogeneity, which means the probability of going from state $s_i$ to state $s_j$ is the same at every time step. When this property holds, the transition probability from state $i$ to state $j$ in $n$ steps can be expressed as the $n^{th}$ power of the transition matrix $P$. Mathematically, this is shown as:
\begin{flalign*}
& \bm{n^{th}} \textbf{ Step Transition Probability} && \\
& p_{ij}^{(n)} = \Pr(X_1 = s_j \mid X_0 = s_i) &&
\end{flalign*}
